# ADR 0003：V1 即引入窄规则引擎

日期：2026-06-23

## 状态

已接受，V1 采用。

## 背景

GestureKit V1 只交付三个动作，但产品方向需要后续支持站点规则、浏览器规则、App 规则和更多动作。如果 V1 把手势直接硬编码为动作，后续扩展会把条件判断散落在输入层、UI 层和执行层。

## 决策

V1 引入规则引擎，但保持范围很窄。

V1 规则只覆盖当前需要的字段：

- `enabled`
- `priority`
- `appBundleId`
- `browserKind`
- `elementType`
- `gesture.type`
- `action.type`

V1 三个动作必须通过 `RuleEngine` 匹配触发，不允许硬编码在输入层或 Chrome 执行层。

## 后果

收益：

- 后续增加站点规则和更多动作时不需要推翻主流程。
- 规则匹配可独立测试。
- 审核和验收有明确边界。

代价：

- V1 相比硬编码多一些结构。
- 需要控制抽象边界，避免提前实现通用自动化平台。

## V1 限制

V1 不实现：

- 完整规则编辑器。
- 条件组。
- 任意正则规则。
- AppleScript 动作。
- shell command 动作。
- 脚本动作。

这些能力必须作为后续版本重新设计和评审。

# GestureKit v2.3.2

## 概述

本补丁版本改进操作记录的证据查看体验：用户可以选择任意操作记录查看对应证据，长证据文本可完整阅读和复制。

## 新增功能

- 无。

## 体验改进

- 操作记录列表支持选择任意一条，右侧显示所选操作的证据时间线和导出入口，不再固定显示最新记录。
- 证据时间线中的长文本自动换行、支持选择复制，并在悬停时提供完整文本提示，避免关键阶段内容被截断后无法查看。

## 修复

- 问题：点击历史操作记录后，右侧详情仍显示最新记录的证据。
- 触发条件：控制中心周期刷新时，页面使用数据源默认的第一条记录作为详情选择。
- 修复内容：控制中心持有用户选择的操作 ID，刷新后按该 ID 解析详情；仅在所选记录不存在时回退到默认记录。

## 兼容性与迁移

- 配置、协议或数据迁移：无。
- 回退方式：回退本 PR 即恢复 v2.3.1 的操作记录详情行为。
- 已知限制：操作记录仍仅展示当前列表保留范围内的项目；已清空展示的记录不会出现在列表中。

## 验证

- 自动化：`swift test`。
- 手动验证：点击多条操作记录，确认右侧证据和导出目标随选择切换；在长证据文本上确认可换行、复制和悬停查看完整内容。

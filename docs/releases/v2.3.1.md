# GestureKit v2.3.1

## 概述

本补丁版本修复多指触控中断后，后续三指点按可能错误复用过期浏览器会话的问题；同时补齐操作失败诊断信息和记录展示上限。

## 新增功能

- 无。

## 体验改进

- 操作记录默认最多展示 50 条，避免长时间使用后列表无限增长。
- 链接打开失败时，默认操作摘要会标明 session、guard 结果以及浏览器动作是否实际下发。
- 开启诊断日志时记录完整 guard 阶段；未开启时仅在失败时保留有限诊断胶囊。

## 修复

- 问题：四指或五指触控中断后，下一次正常三指点按可能显示已识别，却未打开新标签页，原页面反而跳转。
- 触发条件：三指候选已创建后触点数增加，旧候选未被明确结束，后续点按错误关联到已过期的 Chrome guard。
- 修复内容：多指接管时显式拒绝并释放旧候选 session；在所有触点抬起前禁止同一物理触控序列重新入场。

## 兼容性与迁移

- 配置、协议或数据迁移：无。
- 回退方式：回退本 PR 即恢复 v2.3.0 行为。
- 已知限制：跨组件终态关联仍包含既有 FIFO 兼容路径；后续将改为在事件中显式传递 session ID。

## 验证

- 自动化：`swift test`；`npm test`；`npm run build`。
- 手动验证：四/五指接管后，后续正常三指点按可在新标签页打开链接，原页面不跳转；三指滑动保持正常。

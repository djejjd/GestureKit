# GestureKit v2.5.2

## 概述

补丁版本，修复两个问题：v2.5 识别器分帧落地回归（三指轻点被误拒导致链接原地打开），以及 App 重启后扩展需手动刷新才能重连的问题。

## 新增功能

- 无。

## 体验改进

- App 短暂退出重启后，扩展**自动重连**，无需刷新扩展或手动操作。

## 修复

- 问题：三指轻点分帧落地（先 2 指后 3 指）时，识别器把 2 指会话误判为「更高手指数=另一手势」并拒绝，三指轻点候选从未形成 → guard 未 armed → 链接在当前标签原地打开。
  - 触发条件：三根手指不完全同时落地（分帧落地），v2.5 起活跃手指数含 2 时出现。
  - 修复内容：`GestureRecognizer` 在会话仍处于「落地窗口」（未移动）时手指数升高到合法活跃数，升级重建候选并按新手指数重新 armed guard；中途加指/5 指噪声保持原拒绝逻辑。
- 问题：App 重启后，扩展要手动刷新页面/扩展才能重新建联。
  - 触发条件：Host 在 App 的 TCP 连接失败时退出进程，扩展端口断开后无自动重连。
  - 修复内容：Host 自愈——App 掉线不退出，自建 TCP 连接（2s 重试）；扩展删除重连调度逻辑（SW 启动时连接一次）。

## 兼容性与迁移

- 配置、协议或数据迁移：无。
- 回退方式：回退本 PR 恢复 v2.5.1 行为。
- 已知限制：App 长时间离线（>30s）后扩展后台被 Chrome 挂起，需下一次与 Chrome 交互（开页/切标签/开弹窗）唤醒恢复，恢复前的首个 GestureKit 手势可能不生效。

## 验证

- 自动化：Swift 测试 232 测（1 项失败为运行实例持单实例锁，环境性，其余全过）；扩展 vitest 204/204；Host `--self-test` 通过；扩展构建通过。
- 手动验证：三指点击链接开相邻标签页（含分帧落地场景）；退出 App → 重启 → 不刷新扩展直接做手势 → 正常执行。

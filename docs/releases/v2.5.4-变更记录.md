# GestureKit v2.5.4

## 概述

补丁版本。修复系统三指拖移开启时，GestureKit 滑动切换标签同时拖动网页链接、图片或选中文字的问题。App 版本由 `v2.5.4` Git tag 派生，Chrome 扩展同步为 `2.5.4`。

## 修复

- 根据启用的三指/四指滑动绑定，在 Chrome 前台的候选期间建立本地鼠标事件保护；不依赖打开链接绑定是否启用。
- 原生保护仅过滤候选期间开始的左键序列，最长 800ms；全部抬指后最多 120ms 有界收尾。普通鼠标既有拖动的配对抬起保持透传。
- 页面侧补齐 `dragstart`、`selectstart` 保护；滑动终态丢弃暂存或迟到点击，避免恢复为原地导航。
- 页面 guard 绑定原始标签和页面实例，防止切标签后释放错页，以及旧查询迟到覆盖新候选。
- 暂停、配置变化、切换应用、睡眠、断连和停止时清理候选与保护，余指全部抬起前禁止重新入场。
- 本次同步到远端的链接仲裁修复：中间双击窗口内不提前执行单击打开链接；单击提交前重新获取上下文，避免旧 targetRef 过期。

## 兼容性与迁移

- 不新增手势或浏览器动作，不修改系统三指拖移偏好，不新增 Chrome 权限。
- 原生保护需要 GestureKit 的输入监控及辅助功能权限；不可用时记录明确原因并保留页面兜底。页面兜底无法保证抢先阻止系统拖移。
- 更新后重新加载 GestureKit 扩展，并刷新需要验证的网页。
- 原生保护 lease 到期后恢复透传，不恢复或重放已删除的事件。
- 回退方式：通过 PR 回退本次修复，重建上一版本 App 和扩展。

## 开发材料

一并纳入此前未提交的 `.agents/skills/`、`.claude/`、`skills-lock.json` 和跨项目开发启动套件；保持原有技能文件及相对符号链接，不运行其中的安装或配置脚本。

- 发布前自动化：Swift Core 101 + App 153，共 254 项全量通过；Chrome 217 项通过；扩展构建通过；manifest、安装、健康检查、Provider 协议和链接 runner 干跑质量门全部通过。
